# Security policy

Please don't report vulnerabilities in public issues.

Report them privately through GitHub: open the **Security** tab of this repository and choose **Report a vulnerability**. Include the steps to reproduce the problem and what an attacker could do with it.

You'll get a reply within a few days. Please give us reasonable time to fix the issue before you share it publicly.

In scope: the game server (`packages/server`), the site at https://quantmaxxing.web.app, and anything that lets someone change scores, ratings or another player's account.
